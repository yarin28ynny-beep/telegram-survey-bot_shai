# מערכת ניהול סקרי קהילה — בוט טלגרם + ממשק Swing

מערכת לניהול סקרים בקרב קהילת משתמשים בטלגרם: בוט שמצטרפים אליו, וממשק
ניהול גרפי ב-Java Swing ליצירת סקרים, מעקב חי, ותוצאות.

## מבנה הפרויקט

```
telegram-survey-bot/
├── pom.xml                          קונפיגורציית Maven (ללא תלויות חיצוניות)
├── data/                            נוצר אוטומטית — קבצי JSON עם הנתונים
└── src/main/java/com/surveybot/
    ├── Application.java             נקודת הכניסה
    ├── config/Config.java           הגדרות, טוקנים, הגבלות עסקיות
    ├── models/                      Survey, CommunityUser, SurveyQuestion...
    ├── services/                    לוגיקה עסקית: קהילה, סקרים, JSON, ChatGPT
    ├── bot/                         תקשורת עם ה-Telegram Bot API
    └── ui/                          ממשק ה-Swing (חלון ראשי, דפים, רכיבים)
```

הפרויקט **לא משתמש בשום ספריית Maven חיצונית** — כתיבת/קריאת JSON וקריאות
HTTP ממומשות ישירות עם `java.net.http.HttpClient` (חלק מ-JDK 11 ואילך).
הבחירה הזו במכוון: כך ה-build לא תלוי בגישה ל-Maven Central ולא עלול
להיכשל בגלל חסימת רשת או פרוקסי ארגוני.

## הגדרת טוקנים (חובה לפני הרצה ראשונה)

הטוקנים (Telegram Bot, ChatGPT API) **אינם** כתובים בקוד המקור — הם
נטענים בזמן ריצה מקובץ `.env` בשורש הפרויקט (ליד `pom.xml`), כדי
שאפשר יהיה להעלות את הקוד ל-GitHub בבטחה בלי לחשוף אותם.

1. העתק את `.env.example` לקובץ בשם `.env` (ליד `pom.xml`).
2. מלא את הערכים האמיתיים שלך בתוכו.

קובץ `.env` נמצא ב-`.gitignore` ולעולם לא יעלה ל-git — רק
`.env.example` (הריק) עולה.

אם הקובץ חסר או שדה חסר בו, האפליקציה תציג הודעת שגיאה ברורה בפתיחה
במקום להיכשל בצורה מבלבלת.

**חשוב לפני שמעלים לגיטהאב**: ודא ש-`.env` (עם הערכים האמיתיים) אכן
מסומן כ-ignored ולא הצטרף בטעות ל-commit — אפשר לבדוק עם `git status`;
הוא לא אמור להופיע ברשימת הקבצים שישתנו.

## הרצה ב-IntelliJ IDEA (Windows)

### שלב 1 — פתיחת הפרויקט
1. **File → Open**, ובחר את תיקיית `telegram-survey-bot` (זו שמכילה את `pom.xml`).
2. IntelliJ יזהה אוטומטית שזהו פרויקט Maven ויציג הודעה למטה מימין —
   אשר או פשוט המתן (לרוב זה קורה אוטומטית).
3. בפעם הראשונה IntelliJ יוריד את שני ה-plugins הבסיסיים של Maven
   (compiler ו-jar) — זה דורש חיבור אינטרנט חד-פעמי ולוקח כמה שניות.

### שלב 2 — בנייה
בחלונית **Maven** בצד ימין (אם אינה מוצגת: **View → Tool Windows → Maven**):
- לחיצה כפולה על **Lifecycle → compile** (או **package**).

לחלופין, קיצור מקלדת: **Ctrl+F9** (Build Project).

### שלב 3 — הרצה
פתח את `src/main/java/com/surveybot/Application.java` ולחץ על משולש
ה-Run הירוק שליד השורה `public static void main`.

חלון האפליקציה ייפתח, והבוט יתחיל להאזין להודעות בטלגרם ברקע.

## שימוש בבוט (טלגרם)

חברי הקהילה שולחים לבוט **@communityn_bot** אחת מהפעולות הבאות:
- לחיצה על **Start**
- הודעת טקסט **"היי"**
- הודעת טקסט **"שלום"**

כל הודעה אחרת אינה גורמת להצטרפות. משתמש שכבר חבר בקהילה מקבל הודעה
שהוא כבר רשום, ולא מצטרף פעם נוספת.

## שימוש בממשק הניהול

### לשונית קהילה
מציגה בזמן אמת את כל חברי הקהילה — שם, שם משתמש בטלגרם, ומועד הצטרפות.
מתעדכנת אוטומטית כשמצטרפים חברים חדשים, ללא צורך ברענון.

### לשונית סקרים
- **יצירה ידנית**: הקלדת כותרת, שאלה אחת עד שלוש, ו-2 עד 4 אפשרויות
  תשובה לכל שאלה.
- **יצירה עם ChatGPT**: הזנת נושא כללי, וקבלת שאלות מוכנות לעריכה
  ואישור לפני שליחה.
- **תזמון שליחה**: מיידית, או בעיכוב של X דקות — עם countdown חי בזמן
  ההמתנה.
- **מעקב חי**: ברגע שסקר יוצא לדרך, המסך עובר אוטומטית לתצוגת מעקב
  עם countdown לסגירה (5 דקות), סטטיסטיקות (הושלם / בתהליך / טרם
  התחיל), וטבלת משתתפים מפורטת המתעדכנת בזמן אמת.
- **תוצאות**: כשהסקר נסגר (או שכולם השלימו, או שחלפו 5 דקות), מוצגות
  תוצאות עם אפשרויות תשובה ממוינות לפי פופולריות ואחוזים ויזואליים.

## הגבלות עסקיות (לפי דרישות הפרויקט)

- נדרשים **לפחות 3 חברי קהילה** כדי להתחיל סקר.
- **סקר פעיל אחד בלבד** בכל רגע נתון — לא ניתן להתחיל סקר נוסף בזמן שיש
  סקר פעיל.
- סקר נסגר אוטומטית **5 דקות** מתחילתו, גם אם לא כולם השלימו — או
  **מיידית** אם כל המשתתפים השלימו את כל השאלות לפני כן.
- **תזכורת אחת בלבד** נשלחת, 3 דקות מתחילת הסקר, ורק למי שטרם השלים.
- רשימת המשתתפים וסטטוס המענה שייכים **לכל סקר בנפרד** — לא לחבר הקהילה
  עצמו. חבר שהצטרף אחרי תחילת סקר לא משתתף בו, אך משתתף בסקרים הבאים.

## שינוי הגדרות

כל הטוקנים וההגבלות מרוכזים בקובץ אחד:
`src/main/java/com/surveybot/config/Config.java`

## פתרון בעיות נפוצות

**"Cannot resolve symbol" באדום ב-IntelliJ** — לחץ על אייקון ה-Maven
בצד ימין ולחץ על "Reload All Maven Projects" (חץ מעגלי כפול).

**הבוט לא מגיב לטלגרם** — ודא שיש חיבור אינטרנט תקין, ושה-Token ב-
`Config.java` תקף (לא הוחלף/בוטל בצד טלגרם).

**שגיאת ChatGPT API** — שירות הגישור עשוי להיות זמנית לא זמין; נסה שוב
כעבור כמה שניות, או עבור ליצירה ידנית.
